# How this project will be developed

This is a solo capstone project (PROF909/PROF910, Master of Information Technology). It will be developed through Part B (Trimester 3, 2026) following the plan in `/docs/charter.md` and tracked on the [project board](../../projects).

External contributions aren't expected during Part A/B, but feedback and issues are welcome — open a GitHub Issue if you spot something.

**Development approach:** Design Science Research (see `/docs/methodology.md`) with Agile-style delivery discipline — weekly planning, short increments, and regular review against the risk register and evaluation criteria.
